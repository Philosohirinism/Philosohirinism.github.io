紹介

AIが作業を速める一方で、使う側が出力に追われるようになる。効率、標準化された学術生産、自分の文章に自分らしさを残すことを考えます。

内容

道具を使う側から、道具に急かされる側へ

エージェントの出力速度が、読む・判断する・使うための時間を上回る。

文章に残るのは誰の声か

表現が洗練され、批判が増えても、最初の問いや論証の手触りが保たれるとは限らない。

生産性では解消しない不確かさ

取り消せない選択と、現在の努力を評価する未知の未来に立ち返る。

我会觉得我像是一个流水线上的工人欢迎来到这一期的 UjiBricks这一期我想聊一些比较私密的话题这段时间我一直在非常强烈的焦虑情绪当中度过这让我开始思考一件事情就是我为什么会焦虑以及为什么我的生活是越努力我才会变得越焦虑肯定会有很多答案

比如说加速主义啊技术的到来我的 ego 也越来越庞大我有更多更多我想要的东西但是这些答案并不能让我满足 并不能让我止步于所以我就不再焦虑了这段时间从前天开始我想尝试一下 ChatGPT 新推出的一个

agent 的功能就是 dot然后我就下定决心我想充100美元去试试看这给我带来一种更强烈的焦虑一方面是这样的就是我给AI Agent布置了很多的任务我会发现我的生活像是我不再是那个拿着马鞭去赶马的人

而更像是那匹马那个agent他时不时会拿着一根鞭子从我没有准备的时候到来告诉我说我把这个做好了 我把那个做好了这个等待着你去完成那个还没有进行复盘我会觉得我像是一个流水线上的工人我不断被催促着做这个做那个做这个做那个他所生成文件的速度

它所分析论文、分析学者、分析我应该套磁的项目的速度远远大于此时此刻我能够去处理的范畴这是第一方面我所感到焦虑的地方第二方面更来自于他本身因为我并没有一个多余出来给 ChatGPT100美金的预算所以说我会将其视作一个30天的试验

在这30天当中我能留下它并且继续用它的唯一一个指标就是看这30天它能不能够带来100美元的收益今天是第二天很不幸的是它仍然没有让我意识到它在100美元上的收益但是确实它提升了某种意义上我们所认为的效率、速度和能力

但是我发现没有质量这种焦虑对于质量的焦虑或者说对于你自己作为一个人你自己所产出的东西它实际上并没有你的气味的这种焦虑是一种我作为人的主体性上的焦虑我会发现我写的套磁信我所看的书

我所写下的笔记它被 agent 进行一种翻译之后它变成了更华丽的词藻变成了更通畅的逻辑我最近在准备一个Critical Theory 方向的博士的一个计划书我其实在今年的六月份就已经把它写出来了但是现在我想进行再一轮修缮

所以我让 Claude 和 GPT 同时扮演我的红队来进行跟我进行对抗我告诉他们这是我的想法这是我的论证然后我让它们尽可能地驳斥这个时候我发现他们让我感受到痛苦和焦虑的不是说他们真的说出来让我觉得

我确实要改的东西而是他们擅长用非常大量的信息非常多的引用以及非常高密度的反驳来让我意识到一种我无所适从的感觉我会被他的问题越推越远所以到最后在昨天的任务结束的时候我问 GPT 说，我感觉到有点失焦我觉得我们走太远了

我甚至不知道我现在跟你讨论这些跟我原本的论证有什么关系确实,我的论证一定是有瑕疵的但它从某种意义上是我感受到浪漫的是有我自己的气味的是我一读我就知道这就是我的东西但是我不知道它是不是高质量的AI 会告诉我它不是

或者说它需要怎么怎么改它才会变得是之前我写了一封比较实证的proposal也是这样的情况我不是一个擅长实证的人我也不擅长搜索证据我更擅长的是在脑中先想出来一个理论然后通过直觉把它做成一个概念装置

但是不可避免地我需要去证明它需要去用实证去证明它那么在这个过程当中我就终于体会到了AI所带来的保护性写作的一个代价就是我总有问题 我总有缺陷我总需要在某一句话去补

而这种补会让我丧失我论证的完整性或者说连贯性这种连贯性一方面是美感一方面在AI看来也是一种逻辑上的欠缺所以当我仅仅使用了 ChatGPT Pro 两天之后我变得非常的疲劳我变得非常焦虑尽管这种焦虑是在我用它之前就已经持续产生了

我不知道什么是对的但我知道什么是美的但是我所想去生活竞争的评价体系它并不会在意我写的东西美不美它只会在意我写的东西是否是符合标准的这种标准化的生产流程就像现代化一样去虐待着我的精神同时我也会觉得如果脱离了这一套评价体系

那么我该何去何从我可以像小时候一遍又一遍地说着我写东西是美的 是好的但是确实我也在这种现代化的工业化的学术体系当中我也学习到了通过流水线的制作我确实能够规避一些别人已经做出来的东西

我也确实能够让我的论证在学术界更加有价值但是我不知道我不知道我到底要追求的是什么或者说这种焦虑这种anxiety就如同我的论文里头写的一样它永远是面对着那一种
